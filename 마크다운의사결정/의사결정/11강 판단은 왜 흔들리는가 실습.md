동조 모델: 침묵이 이어지면 어떻게 될까?
                                                                        groupthink_model.py

  CONFORM = 0.7   # 아직 아무도 말 안 했을 때, 침묵에 동조할 확률

  def groupthink_trial():
      someone_flagged = False
      for _ in range(N):
          if someone_flagged:              # 이미 한 명이 말했다 → 안전하게 독립 판단
              flag = random.random() < P_INDEP
          elif random.random() < CONFORM: # 아무도 안 말했다 → 동조 압력
              flag = False
          else:
              flag = random.random() < P_INDEP
          if flag: someone_flagged = True
      return someone_flagged


       핵심 차이 한 줄: 아직 아무도 말 안 했을 때만 '침묵 동조' 확률(CONFORM)이 작동한다.
