````text
CONCEPT 1


모든 선택은 비용과 편익의 저울이다

  비용-편익 분석 = 선택의 이득(편익)과 대가(비용)를 같은 저울에 올려 비교하는 것


       편익 (Benefit)                   비용 (Cost)


  • 절감되는 인건비와 시간               • 장비 구매비 · 월 사용료
  • 늘어나는 처리량·매출                • 설치와 교육에 드는 시간
  • 줄어드는 오류와 사고                • 유지보수 · 전기요금 같은 운영비


  순편익 = 편익 − 비용 → 0보다 크면 도입할 가치가 있다
````

## 7페이지

> 전사 방식: PDF 텍스트 레이어

````text
EXAMPLE


2년 쏟은 프로젝트, 접을 수 있는가
이미 개발비 4억 원을 썼다. 완성까지는 2억 원이 더 들고, 완성해도 예상 수익은 1억 원. 계속해야 할까?


  본전 생각 — 매몰비용의 함정                   미래만 보는 계산


  "4억이나 썼는데 여기서 접으면 다 날린다"           앞으로의 비용 2억 > 앞으로의 편익 1억

  → 2억을 더 써서 완성, 수익은 1억              → 지금 중단하면 추가 손실 0원

  → 추가로 1억 원을 더 잃는다                  → 중단이 1억 원만큼 덜 잃는 선택


  이미 쓴 4억은 어느 쪽을 골라도 사라진 돈. 결정에는 미래의 비용과 편익만 넣는다.

````

> 전사 방식: PDF 텍스트 레이어

````text
CONCEPT 4


비용을 구조로 나누기: 고정비와 변동비

       고정비 (Fixed Cost)            변동비 (Variable Cost)
       쓰든 안 쓰든 일정하게 나가는 돈          사용량에 비례해 늘어나는 돈


  • 서버 구매비, 사무실 임대료            • 클라우드 시간당 사용료

  • 소프트웨어 연 단위 라이선스            • 전기요금, API 호출당 과금

  • 정규직 인건비                    • 건당 외주 비용


  총비용 = 고정비 + 변동비 × 사용량 — 이 한 줄이 손익분기점 계산의 재료
````

## 9페이지

> 전사 방식: PDF 텍스트 레이어

````text
TOOL


손익분기점: 선택이 뒤집히는 지점
고정비가 큰 선택(구매)과 변동비가 큰 선택(구독)은 시간이 지나면 유불리가 바뀝니다. 두 선택의 총비용이 같아지
는 지점이 손익분기점(break-even point)입니다.


  손익분기 시점 = 초기 비용의 차이 ÷ 월 비용의 차이 (몇 달을 써야 본전인가)


  손익분기점 이전이라면                         손익분기점 이후라면

  짧게 쓰거나 미래가 불투명할 때는 초기 비용이 없         확실히 오래 쓸 거라면 고정비를 감수하는 쪽(구매)
  는 쪽(구독·임대)이 유리하다.                   이 갈수록 유리해진다.


       핵심 질문은 언제나 "몇 달(년)이나 쓸 건데?" — 사용 기간이 답을 가른다.

````
