3.6 신뢰성 검증


일관성비율 (Consistency Ratio, CR)


    CI   = (λmax − n) / (n − 1)        CR   = CI / RI   RI = 무작위지표 (n에 따른 기준표 값)


●   λmax: 비교행렬의 최대 고유값, n: 비교 기준의 개수

●   CR < 0.1 → 쌍대비교 응답이 논리적으로 일관됨 (사용 가능)

●   CR ≥ 0.1 → 일관성이 부족 → 쌍대비교를 다시 검토해야 함
