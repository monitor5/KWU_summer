## 전사 방식

- `TEXT`: PDF에 내장된 텍스트 레이어를 레이아웃 유지 방식으로 추출
- `OCR`: 페이지 전체가 이미지인 PDF를 한국어+영어 OCR로 판독

## OCR 검수 안내

이미지형 PDF는 원본 자체에 선택 가능한 텍스트가 없어 OCR로 전사했습니다. 작은 글씨, 장식 글꼴, 배경 사진 위 글자, 표·그래프의 축 문구는 오인식 가능성이 있으므로 제출용 인용 전 원본 페이지 대조가 필요합니다.
