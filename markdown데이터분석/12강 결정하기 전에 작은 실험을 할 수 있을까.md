## 4페이지

> 전사 방식: PDF 텍스트 레이어

````text
CONCEPT 1


상관관계와 인과관계는 다르다

  상관관계(correlation) = 두 변수가 함께 움직이는 관계. 인과관계(causation) = 한 변수를 바꾸면
  다른 변수가 실제로 바뀌는 관계.


  두 그래프가 함께 움직이면 우리는 본능적으로 '하나가 다른 하나를 일으켰다'고 생각한다. 하지만 실제로는
  다음 셋 중 하나인 경우가 많다 — 제3의 원인(교란변수)이 둘 다를 움직였거나, 원인과 결과가 뒤바뀌었거나(
  역인과관계), 그냥 우연이었거나. 다음 두 슬라이드에서 각각을 살펴보자.


      핵심 질문 하나: '이 변수를 내가 직접 바꿔도 저 결과가 바뀔까?' — 그렇다면 인과, 아니라면 상관에
      머무는 것이다.
````

````text
                                                              sim_false_positive.py

  import random
  from scipy.stats import chi2_contingency

  def one_trial(n, p_c, p_t):
      c = sum(1 for _ in range(n) if random.random() < p_c)
      t = sum(1 for _ in range(n) if random.random() < p_t)
      _, p, _, _ = chi2_contingency([[c,n-c],[t,n-t]])
      return p


       true rate가 둘 다 10%로 같다는 것이 핵심 — 다음 슬라이드에서 20,000번 반복한 결과를 확인한다.
````
