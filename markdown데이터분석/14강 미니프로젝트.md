````text
STEP 1 · 코드


고트래픽 시기 장애, 20,000번 시뮬레이션
연 60일의 고트래픽 시기 동안, 하루하루 장애가 날 확률(p)로 동전을 던지듯 시뮬레이션하고, 이를 20,000번 반복해 평균 기
대손실을 구합니다.

                                                risk_sim.py   실행 결과
  import random                                               도입 전(p=5%): 2,235.0만원/년
                                                              도입 후(p=8%): 3,599.9만원/년
  def simulate(p_incident, days=60, loss=750):
      total = 0
      for _ in range(20000):
          n = sum(1 for _ in range(days)
                  if random.random() < p_incident)
          total += n * loss
      return total / 20000
                                                              추가 기대손실 약 1,365만원/년

  print(simulate(0.05), simulate(0.08))


       장애 확률이 3%p 늘어난 것뿐인데, 연간 기대손실은 약 1,365만원 늘어난다 — 이 숫자를 STEP2의 비용
       계산에 그대로 가져갑니다.
````
